# Country Silhouette Shape Identification Quiz

A geography quiz that displays a simplified SVG polygon silhouette of a country and challenges you to identify it from multiple-choice options, with difficulty levels, streak tracking, and hint text after each answer.

## Features

- 22 countries with hand-crafted SVG silhouette paths including Italy, Japan, Australia, Brazil, USA, India, Chile, Argentina, UK, France, and more
- Three difficulty levels: Easy (8 iconic shapes, 4 options), Medium (all 22 countries, 4 options), Hard (all 22 countries, 6 options)
- Silhouettes rendered in teal on a dark background for clean visibility
- 4 or 6 multiple-choice answer buttons depending on difficulty
- Score and streak counter tracked throughout the session
- Correct answer highlighted in green, incorrect in red after selection
- Brief geographic hint shown after each answer (e.g. "Boot-shaped peninsula in southern Europe")
- Auto-advances to the next question after 1.8 seconds
- Fully procedurally random question order using Fisher-Yates shuffle
